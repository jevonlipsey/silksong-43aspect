Install it

  1. Rename your original Assembly-CSharp.dll to Assembly-CSharp.dll.bak. Keep it as your backup.
  2. Put the downloaded Assembly-CSharp.dll into the same Managed folder.
  3. Launch the game. It now fills a 4:3 screen at 1280x960 with no letterbox. If it was already open, fully exit and relaunch it.
